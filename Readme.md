Flat Earth Music for Minecraft Java Edition
Soundpack with flat earth music to play in game. Created by MisterP to work from v1.21.9 to v26.3 and optimized for the now playing mod
Put the zip file in your minecraft resourcepack folder and optional install the nowplaying mod to let the mod show the titles
